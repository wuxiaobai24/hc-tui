# 鼠标、触摸与键盘方案

hc-tui 的工作台操作可以从点击菜单进入，原有 Ctrl+B 方案保持默认。
菜单、键盘和 CLI 复用现有动作与布局同步；关闭仍会结束对应程序，退出仍只是 detach。

## 鼠标入口

需要 `ui.mouse_capture = true`。

- Tab 栏右侧 `menu`、侧栏底部 `menu`：打开按窗格、Tab/工作区、终端、全局分组的操作菜单。
- 窗格标题上的 `[...]`：打开窗格操作菜单。只有可见标题且空间足够时显示。
- 右击 Tab 或工作区：选中该对象，打开相关菜单。
- 重命名 Tab：Tab 右键菜单 → rename tab；Pane：标题 `[...]` → rename pane；Agent：侧栏行右键 → Rename，手机上先选中它，再用终端操作菜单中的 rename agent。
- 重命名框预填当前别名，点 Save 保存；清空恢复默认名称。Agent 与对应 Pane 共用终端别名，Tab 名独立。
- 点击选择器行执行；设置可点击切换分区、应用选项。弹窗右上角 `[x]` 关闭。
- 新建、重命名、发送文本等仍需要输入文本，之后可点 Save；危险操作使用 Confirm / Cancel。
- 机器选择器中先点行选中机器，再点 Open、Connect、Rename 或 Remove；Add 不要求选中机器。
- 复制模式中拖动选择文字，点 Copy 复制；Search 输入词后点 Find，`<` / `>` 切换命中，Done 退出。

菜单包含没有绑定快捷键的内置操作，也列出配置中的自定义命令。
高级 CLI 命令及任意 JSON 参数仍通过命令面板或 CLI 使用。

## 拖拽

| 操作 | 手势 | 点击替代入口 |
|---|---|---|
| Tab 排序 | 拖动 Tab 到另一 Tab 上 | Tab 菜单 → 前移 / 后移 |
| 交换平铺窗格 | 拖窗格标题上的 `::` 到另一平铺窗格 | 窗格菜单 → Swap pane → 目标窗格 |
| 移动窗格到 Tab | 拖 `::` 到目标 Tab | 窗格菜单 → move pane → 目标 Tab / 新 Tab |
| 调整分屏 | 拖分隔线 | 窗格菜单 → resize mode → 尺寸按钮 |
| 调整侧栏 | 拖侧栏右边界 | 配置 sidebar_width |
| 浮动窗格 | 拖标题移动，拖右下角改尺寸 | 窗格菜单中切换浮动、置顶、隐藏 |

拖拽只移动视图，不重新创建终端进程。布局变更继续使用已有持久化和共享同步。
跨工作区或共享布局变化导致拖拽源失效时，放弃该次操作。

## Zellij 风格键盘

在 menu → global → Keybindings 中切换，或配置：

```toml
[keys]
preset = "zellij"  # default | zellij
```

这是现有工作台上的模式键盘方案，对齐 [Zellij 的模式操作](https://zellij.dev/documentation/keybinding-presets.html)，并非完整 Zellij 配置或插件兼容层。
原有 Ctrl+B 前缀和显式绑定继续可用；启用后，下表的模式入口键优先由工作台处理。
应用需要这些 Ctrl 组合时，先用 Ctrl+G 锁定，所有普通按键交给应用；再次 Ctrl+G 解锁。

| 入口 | 模式 | 操作 |
|---|---|---|
| Ctrl+P | Pane | h/j/k/l 或方向键聚焦；n/r 右分屏，d 下分屏，x 关闭，f 放大，c 重命名，e 浮动，w 隐藏浮动层 |
| Ctrl+T | Tab | h/l 切换，n 新建，x 关闭，r 重命名，b 将窗格拆成新 Tab，1–9 选择 |
| Ctrl+N | Resize | h/l 改宽，j/k 改高 |
| Ctrl+H | Move | h/j/k/l 或方向键交换相邻窗格 |
| Ctrl+S | Copy / Scroll | 使用现有复制与搜索模式 |
| Ctrl+O | Session | d detach，w 工作区选择，c 设置 |
| Ctrl+G | Locked | 切换按键直通 |

模式下再按同一入口键，或按 Esc / Enter 返回普通模式；Copy / Scroll 按原有规则退出。
桌面底部显示当前模式和按键提示。默认方案不拦截上述 Ctrl 模式键。

## 手机 SSH 终端

窄屏仍为单窗格，点顶栏 switch 可选择工作区、Tab、窗格，或进入全部操作菜单。
窄屏选择器使用更高的行，点击确认及关闭都有明确按钮。

- 在顶栏状态区域横滑：切换前后 Tab。至少移动 6 列且纵向偏移不超过 1 行；switch 按钮不参与识别。
- 在切换列表中上下拖动：滚动列表。发生拖动后松手不会激活列表项。
- 内容区域保留现有拖动翻历史行为；选择文字进入 Copy Mode。

手势通过 SSH 终端转发的鼠标按下、拖动、松开事件识别。Termius / Blink 的实际事件转发和
手势配置需要在真机验证；这里不承诺长按、双指缩放或系统边缘手势。宿主不转发拖动时，
仍可点击菜单中的切换入口；宿主也不转发点击时，需要使用其辅助键盘。
